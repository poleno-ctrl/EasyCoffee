Данный репозиторий создан для выполнения домашнего задания из курса групповой динамики и коммуникации в профессиональной практике программной инженерии, и предназначен для совместной работы нашей команды над анкетой команды-заказчика. В ходе онлайн-встречи с заказчиком были выявлены требования для предстоящего сотрудничества и работы над проектом "Кафетерий льгот".

В настоящем файле README.md описаны цели и перспективы данного проекта, а так же описана структура самого репозитория на GitHub'е. Приведена удобная навигация по репозиторию с отметками о расположениях папок, файлов, тэга. 
##### Цели проекта:
* Практическое освоение методологий сбора и анализа требований.

* Разработка эффективных коммуникационных стратегий в команде.

* Создание полного цикла документации проекта.

* Освоение best practices работы с системой контроля версий Git в команде.

* Внедрение процессов код-ревью и системы аппрувов.

*Для удобства навигации все материалы проекта структурированы по папкам и ключевым точкам процесса.*

##### Навигация:
###### 1. Документация:
**[`/docs/`](./docs/)**: папка со всей проектной документацией.
