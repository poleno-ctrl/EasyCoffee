# Домашнее задание 3. Работа с VCS GIT.
#### Команда Ахо-Карасики

###### Групповая динамика и коммуникации в профессиональной практике программной инженерии
__Данный репозиторий создан для курса групповой динамики и предназначен для совместной работы нашей команды над анкетой команды-заказчика.__

*Для удобства навигации все материалы проекта структурированы по папкам и ключевым точкам процесса.*

##### Навигация:
###### 1. Документация:
`docs/` : папка со всей проектной документацией.
  * Подробная инструкция по внесению изменений, правилам именования веток и коммитов, процессу код-ревью и системе аппрувов.
  * P.S.: файл c правилами работы в данном репозитории можно найти по ссылке `https://github.com/poleno-ctrl/EasyCoffee/blob/launch/docs/RepositoryRules.md` 
  
###### 2. Рабочие материалы: 
`content/` : папка с основными рабочими материалами проекта. 
 * Анкета для извлечения требований: подготовленный опросник для заказчика.
 * Вопросы для интервью: список вопросов, сформированный на основе ответов заказчика.
 * Протокол встречи: официальные результаты проведенного интервью.
 * План коммуникаций: Установленные правила и каналы коммуникации в команде и с заказчиком.
 P.S.: ссылка для перехода к протоколу рабочей встречи - `https://github.com/poleno-ctrl/EasyCoffee/blob/launch/content/Протокол%20встречи.pdf` 
###### 3. Важные точки проекта:
Анкета (финальная версия): для проверки финальной версии анкеты используйте тег `v1.0-Questionnaire`
